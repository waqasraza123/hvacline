# Security policy

HVACLine is a development preview. There is no supported production release or
guaranteed security-response timeline. Production identity, tenant provisioning,
privacy review, and live acceptance remain incomplete.

## Report a vulnerability privately

Use GitHub's [Report a vulnerability](https://github.com/waqasraza123/hvacline/security/advisories/new)
form for this repository. Include the affected commit or release, affected
component, impact, and minimal reproduction steps using fictional data.

Do not open a public issue or pull request with exploit details. Do not include
credentials, access tokens, customer information, transcripts, or recordings.
Remove sensitive values from logs and screenshots before sharing them.

If the private form is unavailable, open a public issue containing only a request
for a private reporting channel. Wait for a private channel before disclosing
technical details.

## Scope and authorization

This policy is a reporting process, not permission to run the software, probe
hosted services, access another business's records, make telephone calls, send
messages, or incur provider charges. Obtain prior written authorization for
testing and follow [LICENSE](LICENSE). No bug bounty is offered by this policy.
